# vmware-vcf

| | |
|---|---|
| Vendor | VMware |
| Platform / product | VMware Cloud Foundation |
| Purpose | Reusable VMware Cloud Foundation automation and documentation |
| Intended capability areas | SDDC Manager, lifecycle and upgrades, workload domains, validation |
| Status | **Starter repository** — structure established; no automation yet |

Content will be added as reusable automation and documentation is developed or sanitized for this platform.
Everything published here is generic: no environment-specific data, no customer or lab identifiers, no credentials.
Layout will follow the LabOps convention (`powershell/`, `ansible/`, `docs/{runbooks,guides,troubleshooting,reference}/`)
as content arrives; folders are created only when they hold content.
